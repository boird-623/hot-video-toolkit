# 爆款拆解框架与开头方案模板

## 一、分析工具（先加载 byted-mediakit-video 技能）

对每个要深度拆解的 Top 视频：

1. `probe-video-metadata`：确认时长、分辨率、码率。
2. `extract-frames`：按"开头 3 秒每 0.5 秒一帧 + 全片每 1-2 秒一帧"抽帧，
   重点看开头画面、字幕样式、贴纸、转场。
3. `asr-subtitles`：取口播逐字稿（带时间戳），用于拆话术结构。
4. `video-understand-router`：对关键帧做画面理解（人物/场景/动作/产品/屏幕文字）。
   命令与参数以该技能 reference 为准，调用前先 Read。
5. 素材足够时无需对每条都全量跑，可先对 Top 5 深度做、其余只看开头与口播。

## 二、逐片拆解维度（每片填一份）

| 维度 | 要记录什么 |
|---|---|
| 基础信息 | 平台、作者、时长、发布时间、点赞/评论/播放、链接 |
| 前3秒钩子 | 第一画面是什么、第一句话是什么、属于哪类钩子（见下）、是否强冲突/反差 |
| 选题/人设 | 科普/剧情/测评/工厂实拍/使用场景/打假避雷；口播者身份（医生/营养师/厂长/素人） |
| 结构节奏 | 按时间轴分段（钩子-痛点-卖点-证据-转化），每段几秒、几次转场 |
| 卖点话术 | 主打卖点（成分/含量/工艺/产地/价格），核心数字与对比（如"是橄榄油的60倍"） |
| 信任状 | 认证、检测报告、地标、工厂、销量、医生/专家背书、原产地实拍 |
| 视觉包装 | 字幕字号/颜色/位置、标题色块、贴纸（爆款/热销/安排）、运镜、BGM、音效 |
| 结尾CTA | 引导动作（点小黄车/评论区/直播间/限时优惠）、钩子话术 |
| 可复用爆点 | 这套结构里哪些元素能直接借鉴到自己产品（只借结构，不搬运画面） |

## 三、开头钩子类型库（判断/创作都用这套）

- **痛点提问**："xxx的人注意了""你是不是也……"
- **反常识/打假**："90%的人都吃错了""别再被商家骗了""有博主说xx是垃圾，我不同意"
- **利益前置**："每天一勺，xxx""一瓶解决xxx"
- **身份代入**："榨油榨了4年半，今天教你鉴别""20亩紫苏籽能榨多少油"
- **数字冲击**："Omega3含量是橄榄油的60倍""含油量高达70%"
- **冲突/悬念**："全家激动抱作一团""结果让我意外"
- **场景/效果演示**：直接展示成品、使用前后对比、工厂实拍
- **权威背书开场**：穿白大褂、报头衔、引用研究/地标
- 记录每个爆款用的是哪类，统计出现频次，优先复用高频钩子。

## 四、横向共性总结

跨片子统计并在《爆款拆解》里给出：
- 最高频的 3 类开头钩子；
- 最常见的时长区间（如 30-60s / 1 分钟以上深科普）；
- 反复出现的核心卖点与数字话术；
- 统一的视觉套路（字幕样式、封面、贴纸）；
- 共性的 CTA 与转化路径。
标注哪些是平台通用规律、哪些可能是该品类专属。
