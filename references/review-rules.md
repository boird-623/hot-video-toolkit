# 预审规则要点、语义复核与平台口径

本文件是词库扫描之外的判断依据。词库命中字面违禁词，模型要按本文件做语义与上下文复核。
主要面向**普通食品/农产品**（如食用油、紫苏籽油）；其他类目按对应法规从严。

## 一、普通食品的合规边界（最关键）

### 绝对不能说（疾病/医疗/保健功效）
- 任何疾病的预防、治疗、缓解：降血压、降血糖、降血脂、降胆固醇、抗炎、消炎、抗癌、防癌、
  治便秘、止咳、护肝、养胃、祛湿、活血化瘀等。
- 任何保健功能：提高/增强免疫力、减肥、减脂、改善睡眠、缓解疲劳、抗氧化、抗衰老、
  益智/补脑/提高记忆力/宝宝更聪明、促进生长发育等——这些只有**取得注册的保健食品（蓝帽子）**
  在**批准的功能范围内**才能说。
- 医疗用语与暗示：药用、医用、处方、疗效、疗程、临床、病例、特效、"吃了我的 XX 好了"。
- 用医生/专家/患者/医院/国家机关名义或形象做推荐证明。

### 普通食品可以说（但要能举证）
- 原料、产地、品种、工艺、口感、风味（如"低温物理压榨""紫苏籽原香"）。
- 营养成分的**客观含量**（如"每 100g 含 α-亚麻酸 XX g"，须与检测报告/营养成分表一致）。
- 食用场景与做法（如"拌酸奶""拌凉菜""直接口服"），但不能宣称这么吃产生功效。
- 合规的健康科普可以中性讲解营养素的**一般作用**，但不得与"吃本品能达到"挂钩。

### 常见违规话术 → 合规改写
| 违规（高风险） | 合规方向 |
|---|---|
| 抗炎、降三高、血糖稳了 | 删掉功效；改为"富含 α-亚麻酸（附检测含量），日常膳食搭配" |
| 提高免疫力、增强体质 | 普通食品删除；有蓝帽子且批了该功能才能说，且按批文原话 |
| 宝宝吃了更聪明、开发智力 | 改为"适合给辅食调味，香醇不腻"，不碰发育/智力 |
| 通便、治便秘、排毒 | 改为"膳食搭配的一种植物油"，不碰肠道功能 |
| 护肝、润肺、安神 | 全部删除 |
| 最健康、第一、顶级、油中之王 | 改为客观描述，删除绝对化 |
| 有机、无添加、地标、蓝帽子 | 无证书一律删除；有证书按证书范围与有效期表述 |

## 二、广告法 / 资质 / 其他红线

- **绝对化用语**：最、第一、唯一、顶级、国家级、世界级、100%、王牌、之王等（第九条）。
- **虚假/夸大**：无依据的销量第一、无效退款、X 天见效、无副作用、绝对安全；
  虚假原价、折扣、库存、限时、"最后一天"必须真实。
- **资质类需举证**：有机认证、绿色食品、地理标志、专利、非遗、老字号、无添加/零添加、
  进口/出口、专供/特供/国宴——没有真实有效凭证一律不能说。
- **保健食品标识**：普通食品不得出现蓝帽子/保健食品/国食健字暗示。
- **导流**：口播、字幕、贴片、评论引导里的微信、QQ、电话、外站平台，平台普遍驳回。

## 三、语义复核清单（脚本扫不出，模型逐条看）

通读 ASR+OCR+标题，重点找：

1. **没说功效词但暗示功效**："血压稳了""血糖不高了""吃了不咳了""喝完就上厕所""瘦了一圈"。
2. **谐音/拆字/符号/空格规避**：特 xiao、神*效、最 好、第 1、加 薇、抗炎写成"抗yán"，
   以及用"炎症/三高/胰岛素"等词绕着说。
3. **绝对化的口语变体**：天花板、封顶、没对手、闭眼入、yyds、断层第一。
4. **画外音/字幕与画面不一致**：画面出现药盒、医院、白大褂、仪器、体检单、"蓝帽子"、
   前后对比图，即使口播没说功效，也构成暗示。
5. **承诺与制造焦虑**："不买后悔""马上涨价""最后 X 件""错过耽误孩子"。
6. **不可证实的背书**："XX 专家说""医院都在用""国家扶持""运动员专供"。
7. 对每条语义问题给出：原句/画面位置、风险点、为什么、可直接替换的说法。

## 四、平台口径（抖音 / 快手 / 百度）

共同红线三家一致：广告法、食品功效/医疗、绝对化、虚假承诺、站外导流。
差异主要在执行与入口，判断时给"通用结论 + 平台标注"：

- **抖音（巨量引擎 / 巨量千川）**：食品类目需提交资质（食品经营许可、生产许可、品牌授权等）；
  功效、导流、绝对化机审严格；普通食品、保健食品、医疗器械分属不同类目，类目不符直接驳回。
- **快手（磁力引擎 / 磁力金牛）**：规则相近，食品同样要资质与类目匹配；对"达人/老铁式"
  夸大口播、私域导流、价格诱导同样拦截。
- **百度（百度营销 / 好看视频信息流）**：信息流创意审核对医疗、保健、金融等更敏感；
  食品功效、绝对化、落地页与视频一致性（标题/口播/落地页不能矛盾）是重点。

**重要**：本预审是基于公开规则的自查，不等于平台官方审核。重大投放前请在各平台投放后台
上传素材走官方机审/人工预审（巨量千川、磁力金牛、百度营销的创意审核），以官方结论为准。
平台规则更新频繁，把握不准的宁严勿松。

## 六、ASR / OCR 工具提示

- `asr-subtitles` 识别口播；`video-ocr` 识别画面字幕/贴纸/标题，二者结果都要扫，
  因为违规常出现在画面贴纸而不在口播。
- 输出带时间戳的文本（SRT/JSON）可直接喂给 `scan_words.py`，报告里能定位到秒。
- 词库 `assets/wordlib.json` 可持续增删：新增类目沿用现有字段（id/name/risk/basis/platforms/
  suggestion/words/patterns），改完用一段已知文案回归验证，避免误报漏报。
