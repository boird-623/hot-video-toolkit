# 溯源原创：找原作者与原视频

目标是判断爆款片段"搬运自谁"，给出**有证据的候选**，不保证唯一，最终由用户确认。
多条线索交叉比单条可靠。

## 一、准备线索（先加载 byted-mediakit-video）

1. `probe-video-metadata`：时长、分辨率、帧率（判断是否被二次剪辑/压缩）。
2. `asr-subtitles`：取口播逐字稿（带时间戳），记录最有辨识度的原话。
3. `extract-frames`：抽 4-8 张关键帧，优先选：
   - 开头第一帧（很多搬运保留原片头）；
   - 人物正脸/主播；
   - 产品特写、包装、字幕标题；
   - 有台标/水印/新闻条/独特场景的帧。

## 二、画面反搜（visual_search）

`visual_search` 按图片内容从全网找相似内容（覆盖抖音视频、图集、电商、全网图、百科）。

1. 关键帧是本地文件，先用 `FileBatchUpload` 上传得到可访问 URL。
2. 逐帧调用 `visual_search`，入参 `image_query.url`（必填）；
   - 可选 `query` 加产品/场景关键词（如"紫苏籽油"）；
   - 可选 `region_of_interest`（[min_x,min_y,max_x,max_y] 归一化）聚焦人物正脸或产品，排除无关字幕。
3. 记录返回结果的标题、链接、类型（视频/图集/百科），重点看是否有**同画面的抖音视频**。
4. 服务偶发失败（返回 search failed）：换一张关键帧、或过一会重试；连续失败就以文案线索为主，
   不要反复重试，也不要因失败就说"没有原创"。
5. 同画面视频还要做下面的时间/内容核验，相似缩略图不等于同一来源。

## 三、口播/文案检索

1. 从逐字稿挑 2-3 句**最独特、非套话**的原话（含具体数字、地名、人名、事件），不要用"家人们"这类通用句。
2. 抖音：`video_search`（工具）用原话/事件词搜索；如新闻类可用"事件+地点+时间"。
3. 全网：`general_search` 搜原话或事件描述（新闻首发常能定位到媒体官网/账号）。
4. 百度好看视频：浏览器按 `references/baidu.md` 搜事件标题/口播。
5. 快手：按 `references/kuaishou.md` 登录后搜（需登录交接）。

## 四、跨平台比对与发布时间

1. 同一画面/文案在抖音、快手、好看视频分别定位，记录每个候选的：平台、账号、链接、发布时间。
2. 用画面+口播双重确认是否同一来源（见判定标准）。
3. 发布时间最早者优先；官方账号（新闻媒体、品牌官号、认证 MCN）优先于转载号。
4. 短视频可能被裁掉片尾/转码，发布时间仍可比对；点进候选主页看其是否还有同系列内容（原创通常有多条同风格作品）。

## 五、判定标准与置信度

- **同源（可比对）**：出现逐帧一致的镜头/人物/场景，或多句口播逐字一致；仅题材、卖点相似不算。
- **高置信**：逐帧 + 逐句一致，且该账号发布时间最早、为官方/认证原创账号。
- **中置信**：画面高度一致但缺少明确发布时间，或仅有口播一致。
- **低置信**：只有题材/脚本结构相似，画面不同。
- **无单一原创（必须如实说明）**：
  - 素材来自共享库存/广告模板/素材库，多个账号使用同一批片段；
  - 新闻素材被大量剪辑，找不到首发；
  - 原片已删除/私密。
  此时列出可追溯的最早/最权威来源，不要硬指一个"原创"。

## 六、报告模板：原创溯源报告_<id>.md

```
# 原创溯源报告：<视频名/链接>（<日期>）
## 送检视频信息
- 平台/链接/时长/分辨率/口播主题
## 溯源线索
- 关键帧：<帧内容> → visual_search 命中…
- 口播金句："<原话>" → 抖音/全网/好看视频命中…
## 候选来源（按置信度排序）
| 置信度 | 平台 | 账号(认证?) | 链接 | 发布时间 | 匹配依据(画面/口播) | 最早? |
| 高 | 抖音 | 大象新闻(媒体) | https://… | 2022-06-24 | 开头镜头+旁白逐字一致 | 是 |
## 结论
- 最可能原创：<账号+链接>，依据：…
- 或：未找到逐帧一致原片 / 疑似共享素材库，说明原因。
## 下载的原片
- 文件名、清晰度、来源链接、是否可公开访问。
```

## 七、下载原片

用户确认后按 `references/` 各平台方法下载最高清晰度原片；
无法访问则保留可公开转载链接并说明。下载后核对时长/分辨率/帧是否与送检片段对得上。
